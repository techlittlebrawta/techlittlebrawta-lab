# Public Repository Content Policy

	echlittlebrawta-lab is public.

This repository is intended for **lab organization, metadata, documentation, configuration examples, and automation that Tech Little Brawta has the right to distribute**.

## Do not commit

- Cisco, Juniper, Palo Alto, Fortinet, VMware, Microsoft, or other vendor firmware/appliance images
- ISO, QCOW/QCOW2, VMDK, VHD/VHDX, OVA, raw disk, or proprietary virtual appliance files
- software obtained under a vendor account unless its license expressly permits redistribution
- product license files, entitlement files, activation keys, serial numbers, or support credentials
- credentials, API tokens, passwords, SSH private keys, certificates containing private keys
- production configurations containing secrets or sensitive customer information

Keep vendor software in authorized private storage and place only documentation/metadata in this public repository.
